# Архитектура

Пользовательская документация: [обзор](overview.md), [использование](usage.md), [словарь](lexicon.md), [TODO](todo.md).

Зависимости идут только внутрь. React не импортируется ядром. Ядро не знает слов «фамилия» и «пол».

```text
приложение
  → form-tail/react
  → пресет ФИО
  → ядро
  → UsageStore, который создал хост
form-tail/ru → ядро
```

Пол считается по текущим значениям одной формы. Частоты считаются по всему приложению. Это разные контуры: в ключе store нет id формы.

## Слои

| Слой | Ответственность |
|---|---|
| `src/core` | нормализация, фильтр алфавита, поиск в уже загруженной корзине, ранжирование, порт store |
| `src/fio` | три части, пол по связке, ленивая загрузка корзины |
| `src/ru` | буквенные корзины и их загрузчик |
| `src/react` | клавиши, хвост, связка полей одной формы |

Публичные входы только через `exports`: `form-tail`, `form-tail/react`, `form-tail/ru`.

## Поток подсказки

1. Поле фильтрует ввод.
2. Пресет по первой букве грузит одну корзину и кэширует её на экземпляр. `ё` идёт в корзину `е`.
3. Ядро ищет префикс бинарным поиском и сортирует: личная частота, вес словаря, алфавит.
4. Пресет отбрасывает кандидатов противоположного пола, если пол связки уверенный.
5. Хвост рисуется отдельно. `commit` увеличивает общий счётчик.
6. `decline` берёт уже принятые части и тот же пол связки. Ядро и файл частот он не меняет. Пол человека и тип склонения фамилии — разные вещи: `Иванова` при мужском поле не превращается обратно в `Иванов`. Окончание вне таблицы остаётся без изменений.

## Файл частот

```json
{
  "version": 1,
  "parts": {
    "surname": {},
    "given": { "алексей": 10 },
    "patronymic": {}
  }
}
```

Ключ — нормализованная форма: нижний регистр, при `foldYo` буква `ё` свёрнута в `е`. Битый документ не становится источником записи. Записи одного store идут в одну очередь: commit во время `write` попадает в следующий снимок. Ошибка чтения отклоняет `ready` и `flush` и не вызывает `write`. Хост пишет во временный файл и заменяет им целевой, чтобы обрыв не стёр частоты. Путь — `app.getPath("userData")`.

## Новый пресет

Новый пресет повторяет `src/fio`: своя фабрика, свой источник корзин, тот же `UsageStore` и `createPartEngine`. Ядро, React-поле и формат файла не меняются. Новая часть добавляется в `NamePart` только если она должна иметь отдельный счётчик.

## Словарь

Корзины и правила обновления списков описаны в [lexicon.md](lexicon.md). Архитектурная граница здесь одна: `form-tail/ru` загружает уже собранную корзину и не импортирует React.
