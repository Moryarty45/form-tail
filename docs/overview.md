# Обзор

`form-tail` дописывает хвост значения прямо в поле. Первая поставка — русские фамилия, имя и отчество. Пользователь видит только продолжение уже набранного начала. Выпадающего списка нет.

Библиотека не зависит от Electron и React. React-поле — отдельный вход `form-tail/react`. Словарь — отдельный вход `form-tail/ru`.

## Возможности

- Хвост рисуется отдельно и попадает в значение только после принятия.
- Строгий режим оставляет русские буквы, дефис и апостроф, в том числе при вставке.
- Мягкий режим не фильтрует ввод. Подсказка всё равно ищется по кириллическому префиксу.
- Каждую часть можно выключить отдельно: `surname`, `given`, `patronymic`.
- Принятое значение получает заглавную первую букву. Одна заглавная в начале не делает капсом весь хвост.
- `е` и `ё` сравниваются как одна буква. В поле остаётся написание из словаря.
- Чаще принятая форма поднимается выше. Счётчик общий для приложения и переживает обновление, если хост хранит файл.
- Имя и отчество фильтруются по уверенному полу связки. Фамилия не отбрасывается и не склоняется.
- Корзина словаря грузится по первой букве, а не целиком.
- Частоты не отправляются и не логируются библиотекой.

## Как выбирается хвост

Для одного начала кандидаты сортируются так:

1. Личная частота принятой формы.
2. Вес словаря.
3. Русский алфавит.

Сейчас у подготовленных форм вес равен 1, поэтому до накопления личной частоты порядок алфавитный. `suggest` частоту не меняет. Она растёт в `commit`, когда принят целый токен длиннее одной буквы и без пробела.

## Пол

Фильтр включается только при уверенном поле.

- Явный `gender` сильнее любого вывода.
- Для имени и отчества сначала используется пол соседнего поля.
- Фамилия может задать пол по окончанию: `-ов/-ева`, `-ин/-ина`, `-ий/-ая` и близкие формы.
- `Женя`, `Саша` и другие формы с полом `unknown` фильтр не включают.
- Короткая или несклоняемая фамилия тоже остаётся `unknown`.

Мужское имя не предлагает отчество на `-овна`. Женская фамилия не предлагает мужское имя. Сама фамилия при этом остаётся доступна в обоих родах: `Иванов` и `Иванова` — разные словарные формы.

## Режимы ввода

| Режим | Поле | Подсказка |
|---|---|---|
| `strict` | русские буквы, `-`, `'`, `’` | кириллический префикс |
| `soft` | без фильтра | кириллический префикс |

Неизвестное русское слово ввести можно. Строгость не означает «только из словаря».

## Частоты

Один `UsageStore` на приложение даёт общий счётчик всем формам. Части между собой не смешиваются: одинаковое написание в фамилии и имени считается отдельно. В ключе нет id формы и id поля.

Без переданного store частоты живут в памяти экземпляра и исчезают вместе с процессом. Для Electron хост передаёт чтение и запись файла в `userData`. Формат файла описан в [architecture.md](architecture.md).

## Клавиши

- Tab и стрелка вправо принимают хвост, если курсор в конце и IME закрыт.
- Escape прячет хвост до следующего изменения.
- Уход из React-поля засчитывает целиком введённый токен, но сам хвост не дописывает.

Новый вид поля добавляется отдельным пресетом. Ядро, React-поле и формат файла частот для этого менять не нужно. Чего нет в первой версии — в [todo.md](todo.md).
